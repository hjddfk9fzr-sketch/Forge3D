# Дорожная карта Forge3D после 1.0

**1.0.0** — исходная точка для совместимых обновлений. В ней зафиксированы форматы сцен и проектов, API Rhai и инструменты MCP. Контрольный проект Workshop Run проверяет редактор, экспорт в Rust, меню, звук, два уровня и восстановление прогресса. [Совместимость](COMPATIBILITY.md) · [Проверки выпуска](RELEASE-CHECKS.md)

| Версия | Приоритет | Как проверяем готовность |
| --- | --- | --- |
| **1.0.1** | ASCII и бинарный FBX, вкладки редактора и горячие клавиши. | Импорт, сохранение и экспорт FBX проверены вместе с редактором. |
| **1.0.2** | Контекстные меню, полный игровой ввод, визуальный редактор UI и редактор Rhai. | Сцену, интерфейс и скрипты можно редактировать, проверять в Play и экспортировать через Rust. |
| **1.0.3** | Просмотр использования моделей по ID во вкладке Assets. | После повторного открытия проекта видны объекты обеих сцен и префаба. |
| **1.0.4** | Пользовательский GLSL-шейдер цвета сцены и поиск использования общих Rhai-скриптов. | Материал с эффектом открывается после сохранения и работает в экспорте. Поиск находит ссылки на скрипт и в сценах, и в префабах. |
| **1.0.5** | Рабочее пространство с режимом Focus и переимпорт моделей по ID в редакторе и CLI. | Замена обновляет геометрию в двух сценах и префабе. Несовместимая замена сохраняет предыдущую версию. |
| **1.0.x** | Исправления по итогам установки редактора и запуска игр на Windows x64, macOS arm64 и Android ARM64. Проверки масштаба, драйверов, касаний, звука и восстановления из фона. | На каждой целевой системе можно получить сборку, пройти Workshop Run и восстановить сохранение. Результат сопровождается журналом и конфигурацией устройства. |
| **1.1.0** | Редактор и ресурсы. Пакетный импорт, просмотр зависимостей, переимпорт по постоянному ID и диагностика отсутствующих ресурсов. Те же операции доступны в MCP или CLI. | После переимпорта модели её экземпляры и префабы сохраняют связи. Перенос папки проекта сохраняет доступ ко всем ресурсам. |
| **1.2.0** | Игровые системы. Запросы к физике, контроллер персонажа, переназначение геймпада, смешивание анимаций и события клипов Rhai. | Отдельный игровой пример одинаково проходит с клавиатурой и геймпадом. Физика, анимация и события проверяются в симуляции MCP. |
| **1.3.0** | Рендеринг и мобильная производительность. Карты нормалей, освещение окружением, уровни детализации и профили качества теней. | Для контрольной сцены записываются сравнимые замеры загрузки, p95 кадра и памяти на настольной системе и физическом Android. Профиль действует в редакторе и экспорте. |
| **1.4.0** | Расширение редактора и автоматизации. Плагины импорта и инструментов, повторяемые сборки из чистого окружения и отчёты CI. | Пример плагина устанавливается из каталога проекта. Агент может проверить проект, собрать игру и получить артефакты через документированный API. |

Добавления 1.x проходят миграционные тесты, проверку Rhai и проверку штатного экспорта. Изменения с несовместимой схемой планируются отдельным поколением с описанием миграции. Приоритет между новыми возможностями и исправлениями определяют тесты контрольных проектов и отзывы с целевых устройств.
