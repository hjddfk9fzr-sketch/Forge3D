# Дорожная карта Forge3D до 2.0

**1.0.0** — исходная точка для совместимых обновлений. В ней зафиксированы форматы сцен и проектов, API Rhai и инструменты MCP. Контрольный проект Workshop Run проверяет редактор, экспорт в Rust, меню, звук, два уровня и восстановление прогресса. [Совместимость](COMPATIBILITY.md) · [Проверки выпуска](RELEASE-CHECKS.md)

Стабильный выпуск — **1.7.0**. [Этапы от 1.6 до 2.0](#forge3d-16-20).

Для каждого этапа запланированы сборка из чистого окружения в CI, загрузка старого проекта, прогон примера и проверка отдельного экспорта. Для изменений физики фиксируются размер сцены и время шага. Отдельно отмечается, какие сборки запускались на реальных устройствах.

Добавления 1.x проходят миграционные тесты, проверку Rhai и проверку штатного экспорта. Изменения с несовместимой схемой планируются отдельным поколением с описанием миграции. Приоритет между новыми возможностями и исправлениями определяют тесты контрольных проектов и отзывы с целевых устройств.

### Условия выпуска 1.5.0

- Каждая бета открывает контрольные проекты 1.4.3 и проверяет новую возможность в отдельной сборке игры. Для каждой публикуются сценарий проверки и известные ограничения.
- Для графических сравнений фиксируются устройство, разрешение, маршрут камеры и профиль качества. Бюджеты производительности уточняются по базовому замеру 1.4.3 до оценки новых профилей.
- Для финального выпуска указываются результаты macOS, среда запуска Windows и доступность проверки на физическом Android. Для каждой найденной регрессии фиксируется статус и сценарий воспроизведения.

## Forge3D 1.6-2.0

Цель — движок и визуальный редактор игр на Rust, в котором независимый автор может начать проект, собрать уровни, добавить логику, отладить её и выпустить законченную 2D- или 3D-игру. Сравнение с Unity ведём по этому рабочему процессу. Для 2D ориентир включает спрайты, редактор тайлов, физику, UI, профилирование и публикацию. [Рабочий процесс создания 2D-игр в Unity](https://docs.unity3d.com/6000.1/Documentation/Manual/2d-game-creation-wokflow.html)

В версии 1.5.0 уже есть сцены, префабы, реестр компонентов, физика 3D, анимация, материалы и экспорт. Приоритет 1.6 вытекает из текущего устройства проекта. Стандартный экспорт включает игровые системы из `src/workshop.rs`. Пользовательская Rust-логика должна стать частью папки игры и работать в Play и экспорте с одним набором API.

| --- | --- | --- |

Редактор запускает их через отдельный игровой процесс с циклом сохранение → сборка → Play. Стабильные ID ресурсов, обновление импортов и понятная диагностика сборки в Console. | Из шаблона создаётся игра с собственным Rust-компонентом, который виден в Inspector. После изменения кода одна и та же логика работает в Play и готовой сборке. Ошибка компиляции показывает файл и строку, сохранённую сцену можно открыть и исправить. |

### Контроль готовности 2.0

- **2D-проект:** платформер, собранный из нового шаблона. Два уровня, тайловые коллизии, анимация, меню и прогресс. Игровой цикл можно собрать визуально.
- **3D-проект:** новая небольшая игра с персонажем, NPC, навигацией, префабами и своей системой на Rust. Cloud Relay и Workshop Run остаются регрессионными проектами.
- **Переносимость:** зафиксированы версии Rust и зависимостей, список ресурсов и параметры сборки. На чистой машине исходный проект собирается командой из руководства, а готовая игра запускается независимо от редактора.
- **Стабильность:** миграция сохраняет ID сцен, ресурсов и префабов. Для типовой 2D- и 3D-сцены фиксируются p95 кадра, память и загрузка на выбранных устройствах. Бюджеты задаются по базовым замерам перед оптимизацией.
- **Следующий этап 1.8:** коллизии, навигация, граф анимации и профилирование для 3D.
