# Проверки Forge3D 1.5.0

На Apple Silicon прошли 76 тестов Forge3D, форматирование и строгий Clippy. Релизный валидатор открыл все четыре сцены проектов Cloud Relay 1.4.3 и beta.5. Новые проекты Cloud Relay и Workshop Run экспортированы и собраны отдельно. Workshop Run прошёл проверку всех четырёх сцен.

| Что проверяли | Результат |
| --- | --- |
| Самостоятельная Cloud Relay | Обе трассы, перезапуск и повторный забег. Проверены команды шагов, карты нормалей, настройки света и теней и уровни LOD. Два теста прошли на Mac и в Windows-сборке через CrossOver. |
| macOS arm64 | Редактор и игра из ZIP имеют версию 1.5.0 и ad-hoc подпись. Оба приложения открыли окна и отрисовали по восемь кадров. |
| Windows x64 | Оба EXE в формате PE32+ x86-64 открыли окна и отрисовали по восемь кадров в чистой среде CrossOver. Обе игровые сборки прошли проверку встроенных сцен. |

Нативный запуск на ПК с Windows, Linux и физическом Android в этом прогоне не проверялся. ADB не обнаружил подключённого устройства. Ниже сохранены замеры LOD и профилей теней из бета-версий.

## Проверки Forge3D 1.5.0-beta.5

На Apple Silicon прошли 76 тестов Forge3D, форматирование и строгий Clippy. Проверены переключение сразу на несколько уровней, гистерезис около порога, неизменность коллайдера, замена уровня через CLI, откат ошибочной замены, сохранение ресурса и экспорт. Локальные приложения arm64 с ad-hoc подписью отрисовали по восемь кадров. Отдельно собранная Cloud Relay прошла обе трассы, а самостоятельный Workshop Run загрузил все четыре сцены. Проекты Cloud Relay из 1.4.3 и beta.4 прошли валидацию в beta.5.

### Сравнение LOD в Cloud Relay

Apple M4, OpenGL, 800 × 550, Desktop. Два прогона на режим в отдельных процессах. Сцена `amber`, 30 кадров прогрева и 120 измеряемых кадров. По циклу камера перемещается от Z = 1 до −10, азимут меняется с 15° до 45°, наклон 28°, дистанция от 8,5 до 27,5. Время отрисовки измерено до завершения GL-команд с `glFinish`. Загрузка измерена от чтения проекта до развёрнутой сцены, без подготовки GPU. Память — пиковый RSS процесса по `/usr/bin/time -l`, без разделения GPU-памяти.

| Режим | p95 отрисовки, мс | Пиковый RSS, МиБ | Загрузка проекта и сцены, мс |
| --- | --- | --- | --- |
| 1.4.3 | 10,48–10,55 | 113,94–113,95 | 0,53–1,05 |
| beta.5, все модели в полной детализации | 11,62–12,58 | 119,42–119,50 | 1,32–5,49 |
| beta.5, LOD включён | 11,80–11,94 | 119,23–119,41 | 1,19–1,31 |

За 120 кадров beta.5 отправила в проход цвета 115 728 треугольников моделей вместо 383 040 в полной детализации, на 69,8% меньше. Счётчик исключает встроенные примитивы и повторную отправку в теневой проход. Диапазоны p95 beta.5 с LOD и без него перекрываются. В 1.4.3 сцена и рендерер проще, поэтому сравнение со стабильной версией отражает результат всего обновления.

ADB не обнаружил подключённого устройства. Замеры на физическом Android и запуск этой версии на Windows остаются открытыми.

## Проверки Forge3D 1.5.0-beta.4

На Apple Silicon прошли 74 теста Forge3D, форматирование и строгий Clippy. Проверены сохранение обоих наборов настроек теней, активного профиля и освещения небом после повторного открытия и экспорта. Проекты Cloud Relay 1.4.3 и beta.3 прошли валидацию. Самостоятельная Cloud Relay сохранила разные профили двух трасс и успешно прошла обе. Оба локальных приложения arm64 запустились.

### Сравнение теней в Cloud Relay

Оптимизированная сборка на Apple M4, OpenGL, 800 × 550. Сцена `amber`, два прогона каждого профиля, 30 кадров прогрева и 120 измерений. Камера за один цикл проходит от Z = 1 до Z = −10, азимут увеличивается с 15° до 45°, наклон 28° и расстояние 8,5 постоянны. Время от начала отрисовки до завершения GL-команд измеряли с `glFinish`, без ожидания следующего кадра. Во всех прогонах профиль менялся в одном рендерере.

| Профиль | Карта, покрытие, выборки | p50, мс | p95, мс |
| --- | --- | --- | --- |
| Desktop | 1024 × 1024, 14, 5 | 10,20–10,46 | 10,63–12,32 |
| Mobile | 512 × 512, 9, 1 | 9,25–9,45 | 9,91–12,40 |

Медиана Mobile ниже в обоих прогонах, диапазоны p95 перекрываются. Контрольные GPU-кадры подтвердили изменение освещения матового материала и отражения металлического материала при смене Day, Sunset и Night. Физический Android, Windows и Linux в этом прогоне не проверялись.

## Проверки Forge3D 1.5.0-beta.3

На Apple Silicon прошли 73 теста Forge3D, форматирование и строгий Clippy. Проверены glTF и GLB, авторские и вычисленные тангенты, зеркальные UV и отражённая трансформация скелетного меша. Материал палубы и локальное переопределение силы сохраняются при переимпорте, записи проекта и экспорте. В проектах Cloud Relay 1.4.3 и beta.2 все четыре сцены прошли валидацию.

На контрольных GPU-кадрах одна палуба отрисована с силой 0 и 1, затем с изменённым направлением света. Во всех трёх кадрах камера и геометрия совпадали. Отдельно собранная Cloud Relay загрузила карты нормалей палуб и прошла обе трассы. Оба приложения arm64 с ad-hoc подписью открыли окна. Windows, Linux и Android в этом прогоне не проверялись.

## Проверки Forge3D 1.5.0-beta.2

На Apple Silicon прошли 70 тестов Forge3D, форматирование и строгий Clippy. Проверены интерполяция поз, повторная смена клипа без скачка и звуковые метки только от целевого клипа. Старые проекты Cloud Relay 1.4.3 и beta.1 открываются и проходят валидацию.

В отдельно собранной Cloud Relay прошли тесты Idle → Walk → Run → Idle, звуковых команд и прохождения обеих трасс. Приложения редактора и игры arm64 с ad-hoc подписью отрисовали по восемь кадров. Ручное прослушивание beta.2 и проверки на Windows, Linux и Android остаются открытыми.

## Проверки Forge3D 1.5.0-beta.1

На Mac с Apple Silicon прошли 68 тестов Forge3D, форматирование и строгий Clippy. Проверены пауза, изменение скорости, обратное воспроизведение и граница цикла. Сохранённый проект Cloud Relay и экспортированные сцены проверены с локальной меткой и обработчиками Rust и Rhai. В отдельно собранной Cloud Relay подтверждены две звуковые команды за проход по платформе и отсутствие команд в покое и в прыжке.

Локальные приложения редактора и игры проверены по arm64, ad-hoc подписи и запуску окна. Оба проекта Cloud Relay, 1.4.3 и beta.1, прошли проверку четырёх сцен. Пользователь подтвердил работу звука в beta.1. Прогон на Windows, Linux и Android в этой бете не проводился.

## Проверки Forge3D 1.4.3

На Mac с Apple Silicon прошли 66 тестов Forge3D, включая сборку и запуск теста самостоятельного экспорта жетонов. В новом тесте CLI импортирует GRID и переимпортирует остров, используемый в двух сценах и префабе. Проверены ID, положения объектов и сохранённый проект при неверном символе, разной длине строк и пустой карте. Самостоятельно собранная игра загрузила новый контур острова в обеих сценах.

В релизе 1.4.3 редактор и Cloud Relay для macOS прошли проверку версии, архитектуры arm64 и ad-hoc подписи после распаковки. EXE проверены как PE32+ x64. Каждое приложение отрисовало восемь кадров, Windows-сборки запускались в CrossOver. Cloud Relay прошла проверку всех сцен на обеих сборках. `island.grid` из релиза импортирован в проект через CLI.

Запуск на ПК с Windows и проверки Linux и Android остаются открытыми.

### Повторить проверки

Из корня репозитория со скачанными зависимостями выполните:

```sh
cargo test --locked --offline -- --include-ignored
cargo run --locked --bin forge3d-batch -- validate Cloud-Relay.forge-project.json
```

Для второй команды положите [редактируемый проект из релиза](https://github.com/hjddfk9fzr-sketch/Forge3D/releases/download/v1.4.2/Cloud-Relay.forge-project.json) в рабочий каталог. В экспортированной игре параметр `--check-scene` проверяет встроенные сцены, а `--window-smoke` открывает окно на восемь кадров.
