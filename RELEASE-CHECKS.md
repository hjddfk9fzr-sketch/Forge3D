# Проверки Forge3D 1.4.2

Проверены исходники тега [v1.4.2](https://github.com/hjddfk9fzr-sketch/Forge3D/tree/v1.4.2). На Mac с Apple Silicon прошли 65 тестов Forge3D, включая тест, который экспортирует новый Cargo-проект и запускает его собственную проверку подбора жетонов.

| Что проверяли | Результат |
| --- | --- |
| Компоненты и префабы | После сохранения и повторного открытия два жетона из одного префаба сохранили разные радиусы подбора. Курьер подбирает жетоны на заданных расстояниях в Play и отдельном экспорте. Revert восстанавливает радиус шаблона. |
| Совместимость | Валидатор 1.4.2 принял все четыре сцены редактируемого проекта Cloud Relay из выпуска 1.4.1. |
| Cloud Relay | Релизный JSON прошёл валидацию и экспорт. Автотест отдельно собранной игры проверил падение, перезапуск, обе трассы и повторный забег после финиша. |
| macOS arm64 | Оба ZIP распакованы. Проверены версия 1.4.2, архитектура arm64 и ad-hoc подпись каждого приложения. Редактор и игра отрисовали по восемь кадров. Игра прошла проверку встроенных сцен. Нотарификация Apple не выполнялась. |
| Windows x64 | Редактор и игра собраны в формате PE32+ x86-64. В чистой среде CrossOver на Mac оба EXE открыли окно и отрисовали по восемь кадров. Игра прошла проверку встроенных сцен. Запуск на физическом ПК с Windows остаётся открытым. |

Проверки Android и Linux для этого выпуска отдельно не проводились. Результаты предыдущих выпусков сохранены в [истории проверок до 1.4.1 включительно](https://github.com/hjddfk9fzr-sketch/Forge3D/blob/v1.4.1/RELEASE-CHECKS.md).

## Повторить проверки

Из корня репозитория со скачанными зависимостями выполните:

```sh
cargo test --locked --offline -- --include-ignored
cargo run --locked --bin forge3d-batch -- validate Cloud-Relay.forge-project.json
```

Для второй команды положите [редактируемый проект из релиза](https://github.com/hjddfk9fzr-sketch/Forge3D/releases/download/v1.4.2/Cloud-Relay.forge-project.json) в рабочий каталог. В экспортированной игре параметр `--check-scene` проверяет встроенные сцены, а `--window-smoke` открывает окно на восемь кадров.
