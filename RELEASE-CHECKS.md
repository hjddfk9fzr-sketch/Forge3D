# Проверки Forge3D 1.3.0

На macOS ARM64 прошли 54 теста движка, форматирование и строгий Clippy для всех целей. На отдельной сцене проверены падение, опора, высота прыжка, повторное нажатие в воздухе, диагональное движение вдоль стены и два предела уклона. В Workshop Run закрытая дверь остановила капсулу. После открытия пилот прошёл через неё, получил жетон и достиг следующего уровня. Этот маршрут также прошёл в отдельно скомпилированном экспортированном проекте, все четыре сцены прошли `--check-scene`.

Для замера CPU в экспортированной release-сборке пилот упирался в закрытую дверь. На входной сцене с 9 объектами и 6 телами после 120 кадров прогрева измерены 1800 вызовов `GamePlayback::tick` с шагом 1/60 с. Медиана составила 36,5 мкс, p95 — 48,9 мкс. Время включает физику, скрипты и игровые системы без рендеринга.

Редактор из релизного ZIP и отдельная игра отрисовали по восемь кадров. Проверены arm64, версия bundle 1.3.0, целостность ad-hoc подписи распакованного приложения. Сборка распространяется без нотарификации Apple. Физические Windows и Android в этом прогоне не использовались.

## Проверки Forge3D 1.2.0

Дополнительный тест скомпилированного экспортированного Cargo-проекта подтвердил подбор жетона и изменение инвентаря. Проверены удаление коллайдера, обновление экземпляра скрипта и откат при неизвестном префабе.

В релизном профиле собраны редактор, CLI и MCP. Приложение Forge3D.app извлечено из ZIP и прошло `codesign --verify --deep --strict`. Редактор и отдельная игра отрисовали по восемь кадров. Пакет предназначен для Apple Silicon и имеет ad-hoc подпись. Версия 1.2.0 на физических Windows и Android в этом прогоне не запускалась.

## Проверки Forge3D 1.1.0

- После переноса папки и удаления исходных файлов проверены зависимости сцен и префаба, переимпорт скрипта, создание экземпляра префаба и экспорт игры со встроенными ресурсами. Тест переимпорта FBX проверяет обе сцены и префаб.
- Проверены диагностика отсутствующих ID и локальных индексов, путь к отсутствующей библиотеке OBJ или текстуре, а также имя отсутствующего буфера glTF.
- Проверены четыре сцены Workshop Run, экспорт в отдельный Cargo-проект, релизная сборка игры, запуск с `--check-scene` и отрисовка восьми кадров при 1280×720. Нативный запуск именно 1.1.0 на Windows, Linux и физическом Android остаётся непроверенным.

## Как завершить проверку

1. Запустите [.github/workflows/platforms.yml](.github/workflows/platforms.yml) в GitHub Actions. Опция `desktop_graphics` дополнительно запускает проверку окна на Windows и macOS. Сохраните ссылку на запуск, артефакты и журналы.
2. На Windows x64 и Apple Silicon создайте демо командой `cargo run --locked --bin forge3d-batch -- demo demo.forge.json` и соберите его командой `cargo run --locked --bin forge3d-batch -- build demo.forge.json demo-build release`. Из каталога `demo-build` запустите `target/release/forge-game.exe --window-smoke` на Windows или `target/release/forge-game --window-smoke` на macOS. Проверьте также обычный запуск из `dist`, включая извлечённый пакет `.app` на macOS. В окне должны быть анимированная рука, её тень и две сферы. Клавиши движения должны сдвигать розовую сферу. Запишите ОС, архитектуру, GPU и сохраните журнал.
3. На физическом устройстве Android ARM64 установите демонстрационный APK командой `adb install -r Forge3D-0.1.0-beta.2-demo-arm64.apk`. Откройте приложение и проверьте анимацию, тень и перемещение розовой сферы экранными стрелками. Нажмите Home, вернитесь к игре через список недавних приложений и повторно проверьте анимацию и ввод. Сохраните модель устройства, версию Android и журнал `adb logcat -d`.
