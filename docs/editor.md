## Стартовый экран

При запуске Forge3D открывается **Project Hub**. В **Templates** можно создать проект из пустой 2D- или 3D-сцены либо из демонстрационной игры. Сохранённые и открытые проекты появляются в **My projects** и остаются там после перезапуска. Чтобы добавить несколько своих проектов, в **Browse** перейдите в общую папку и нажмите **Add projects from this folder and subfolders**. **Remove** убирает ссылку из списка, файлы проекта сохраняются.

Из редактора стартовый экран открывается через **File → Project Hub**. Кнопка **Back to editor** возвращает к открытой сцене. Перед открытием другого проекта редактор показывает подтверждение, если в текущем есть несохранённые изменения.

## Работа со сценой

- **Hierarchy** содержит объекты сцены. Добавляйте примитивы или выбирайте объекты в списке и в 3D-окне. В **Inspector** доступны позиция, углы поворота, масштаб, видимость и параметры поведения.
- Правый клик в сцене открывает меню создания объектов. Клик по объекту в сцене или в **Hierarchy** также открывает команды **Frame**, **Duplicate** и **Delete**. Когда курсор над сценой, WASD перемещают камеру. В 2D они сдвигают вид по X и Y. В 3D W и S летят по направлению взгляда с учётом наклона, A и D смещают камеру вбок. Пробел поднимает камеру, C опускает, Shift ускоряет. Правая кнопка включает свободный обзор, Alt с правой кнопкой вращает камеру вокруг точки интереса. Средняя кнопка перемещает камеру, колёсико меняет расстояние. **Frame** центрирует выбранный объект. Перетаскивайте цветную метку оси в 3D-окне, чтобы перемещать объект. **Scene settings** открывает параметры камеры, используемой в игре.
- **File → Import model…** принимает путь к OBJ, FBX, glTF, GLB или GRID. Поддерживаются статические треугольные меши, базовый цвет и цветовые текстуры. Для OBJ расположите MTL и его PNG/JPEG-текстуры рядом с исходной моделью или сохраните их относительные пути. Для glTF оставьте внешние ресурсы по путям, указанным в файле.
- Вкладка **Assets** позволяет создавать экземпляры уже импортированных моделей. **Save…** сохраняет сцену со всеми импортированными ресурсами в один файл `.forge.json`. Относительные пути в окнах ввода отсчитываются от рабочего каталога редактора.

Объекты имеют постоянные ID. Выберите родителя в раскрывающемся списке **Inspector**. Иерархия отображается с отступами, дочерние объекты наследуют трансформацию и видимость родителя. При переподчинении сохраняются локальные координаты. **Undo** и **Redo** доступны на панели инструментов и через Ctrl/Cmd+Z и Ctrl/Cmd+Shift+Z. Удаление поддерева тоже можно отменить.

## 2D-сцены

**File → New 2D scene…** создаёт пустой тайловый уровень с ортографической камерой. Ось X направлена вправо, Y вниз, размер клетки равен одной мировой единице. Колесо меняет масштаб, средняя кнопка мыши перемещает камеру. **Inspector → Canvas and camera** управляет размером уровня, фоном и гравитацией. **Use editor camera** сохраняет текущий вид как игровую камеру.

1. В **Inspector → Import sprite atlas** введите путь к PNG, ID и ширину и высоту кадра. Прямоугольные кадры одинакового размера идут слева направо, затем сверху вниз. PNG встраивается в сцену. Поддерживаются изображения до 2048 × 2048 и 8 МиБ.
2. В **Tile brush** выберите слой и атлас или цвет. Включите **Paint tiles** над сценой. Левой кнопкой рисуйте, правой стирайте. **Solid** включает коллизии слоя. **Tile** начинается с 1, ноль хранится как пустая клетка. **Order** задаёт порядок отрисовки. Большие значения лежат ближе к игроку.
3. Нажмите **+ Object**, выберите объект и добавьте **Sprite**. Укажите индекс первого кадра от нуля, количество кадров и FPS. При FPS = 0 остаётся первый кадр. Выберите **Add 2D body** для прямоугольного коллайдера. **Static** останавливает движущиеся тела, **Dynamic** падает под действием гравитации, **Character** реагирует на движение и прыжок, **Sensor** отправляет события `trigger_enter` и `trigger_exit` в Rhai.
4. Выберите **Project → Create from current scene…**. Дополнительную 2D-сцену можно создать из текущей через **Project → Add scene…**, оставив путь к файлу пустым. Проверьте стартовую сцену в **Play** и экспортируйте проект через **File → Export Rust…**.

В 2D используются прямоугольные коллайдеры в корне сцены. Персонажи и динамические тела взаимодействуют с тайлами и статическими телами. Сенсоры отслеживают движущиеся тела. Размер коллайдера задаётся отдельно от размера спрайта.

**Project → Open Afterlight (2D)…** содержит готовые настройки и скрипты. Сцены `menu`, `yard`, `bridge` и `finish` показывают меню, управление, слежение камеры, перезапуск при падении и переходы через сенсор. Команды CLI создают те же данные в файл.

```sh
forge3d-batch demo-2d scene.forge.json
forge3d-batch platformer-demo Afterlight.forge-project.json
forge3d-batch validate Afterlight.forge-project.json
forge3d-batch export Afterlight.forge-project.json afterlight-source
```

### FBX

Импортируйте модель через **File → Import model…**. Для проверки можно использовать [тестовый FBX из репозитория](https://github.com/hjddfk9fzr-sketch/Forge3D/blob/v1.4.2/tests/fixtures/model-ascii.fbx). Поддерживаются ASCII и бинарные FBX, триангуляция полигонов, преобразования узлов, UV, нормали, базовые материалы и встроенные или внешние текстуры PNG/JPEG. Геометрия приводится к метрам и оси Y вверх. Для внешних текстур сохраните относительные пути или положите файлы рядом с FBX. Результат сохраняется в проекте и экспортируется в Rust вместе с текстурами.

FBX импортируется как статический меш. Для скелета и анимационных клипов используйте glTF/GLB.

### Рабочая область и горячие клавиши

Иерархия слева поддерживает сворачивание веток. Инспектор справа редактирует выбранный объект. В нижней панели вкладки **Project**, **Assets** и **Console** разделяют файлы, импортированные ресурсы и сообщения. Панели можно менять местами и масштабировать через **Workspace → UI scale**. Над видовым окном расположены **Scene / Game** и **Focus**. Внутри 3D-вьюпорта слева доступны **Select**, **Move**, **Rotate** и **Scale**. Справа находится куб ориентации с гранями ±X, ±Y и ±Z. Щелчок по грани направляет камеру вдоль соответствующей оси. Focus временно скрывает боковые панели и нижнюю панель, повторное нажатие возвращает их. Верхняя строка содержит **Play**, **Pause** и **Step**. В инспекторе можно свернуть Transform и Behaviors.

| Клавиши | Действие |
| --- | --- |
| Ctrl/Cmd+N, O | Новая сцена, открыть файл |
| Ctrl/Cmd+S, Shift+Ctrl/Cmd+S | Сохранить, сохранить как |
| Ctrl/Cmd+I | Импортировать модель |
| Ctrl/Cmd+Z, Shift+Ctrl/Cmd+Z | Отменить, повторить |
| Ctrl/Cmd+D, Delete | Дублировать или удалить объект вместе с потомками |
| Q, G, E, R | Выбор, перемещение, поворот, масштаб объекта в 3D |
| WASD, Shift | Перемещение камеры над видовым окном, ускорение |
| Space, C | Подъём и спуск 3D-камеры |
| Правая кнопка, Alt + правая кнопка | Свободный обзор или орбита 3D-камеры |
| F | Приблизить выбранный объект |
| F5, F6, F7 | Play/Stop, Pause/Resume, один кадр на паузе |
| Esc | Закрыть диалог |
| Ctrl/Cmd + «+», «−» или «0» | Изменить масштаб редактора или вернуть 125% |

Подсказки доступны в **Help**. Клавиши инструментов сцены отключаются во время ввода текста и в режиме игры. В режиме Play включите **Workspace → Send all keys to Play**, чтобы передать игре и клавиши F5–F7. Остановить игру, поставить её на паузу или выполнить один кадр можно кнопками на панели.

В меню **Tools** доступны **Test scene**, **Capture PNG** и **Build**. Тест прогоняет 60 кадров и показывает ошибки Rhai. Захват сохраняет программный предпросмотр игровой камеры. Текущий этап фоновой сборки виден в строке состояния. **Console** показывает результат, журнал и пути к артефактам. В меню **Tools** можно выбрать **Cancel build** или **Retry build…**. Повтор использует снимок исходной сцены и тот же профиль, а результат записывает в новую папку. Для Android нужен настроенный инструментарий, перечисленный в README экспортированного проекта.

## Проекты, сцены и префабы

В редакторе выберите **Project → Create from current scene…**, чтобы перенести текущую сцену в проект, или откройте готовый пример через **Project → Open two-scene demo…**. **Add scene…** добавляет пустую сцену или импортирует существующий файл `.forge.json`. **Edit scene** сохраняет рабочие изменения в открытом проекте и переключает сцену. Нажмите **Save project…**, чтобы записать все сцены на диск.

Манифест `.forge-project.json` хранит сцены, модели, скрипты и префабы вместе. Одинаковые модели и общие скрипты переиспользуют записи с постоянными ID. **Shared assets** добавляет модель или скрипт из библиотеки в активную сцену. **Create prefab from selection…** сохраняет выбранный объект и его потомков. **Insert prefab** создаёт редактируемую копию с новыми ID объектов и сохраняет связи внутри иерархии.

**Use active scene at launch** задаёт стартовую сцену экспорта и сборки. Настройки окна и приложения берутся из стартовой сцены. **Play** в редакторе начинает с открытой сцены, чтобы её можно было проверить независимо от точки входа игры.

Rhai может запросить переход, вернув `object.next_scene` со строковым ID сцены из `start`, `update` или `on_event`. После перехода объекты, физика и состояние скриптов загружаются из сохранённой сцены. В демонстрации нажмите **D** или стрелку вправо, чтобы попасть в мастерскую, затем **A** или стрелку влево для возврата. На Android используйте экранные стрелки.

```sh
cargo run --locked --bin forge3d-batch -- project-demo demo.forge-project.json
cargo run --locked --bin forge3d-batch -- project-list demo.forge-project.json
cargo run --locked --bin forge3d-batch -- project-start demo.forge-project.json workshop
cargo run --locked --bin forge3d-batch -- export demo.forge-project.json game-source
```

Чтобы перенести свой проект, начните с `project-new OLD.forge.json NEW.forge-project.json` и добавьте сцены командой `project-add PROJECT SCENE_ID SCENE.forge.json`. Команды `export` и `build` принимают как файлы сцен, так и манифесты проектов.

## Библиотека ресурсов

1. Откройте проект и перейдите в **Assets → Batch import…**. Отметьте файлы в текущей папке браузера или вставьте по одному пути на строку. Можно смешивать OBJ, FBX, glTF, GLB, GRID и Rhai. Если любой файл не читается или скрипт не компилируется, вся партия отклоняется. Повторный импорт одинакового ресурса возвращает прежний ID.
2. Используйте **Project → Shared assets**, чтобы добавить модель или скрипт из библиотеки в активную сцену. **Assets → Dependencies…** показывает модели и скрипты, включённые в выбранную сцену или префаб. **Where used…** показывает объекты, которые используют выбранный ресурс, включая текущие правки активной сцены.
3. В **Where used…** выберите **Reimport model…** или **Reimport script…** и укажите новый файл. Имя и ID сохраняются во всех сценах и префабах. Редактор начинает новую историю Undo активной сцены после успешного переимпорта. Для записи изменений на диск нажмите **Save**.

Модели, текстуры и скрипты встроены в манифест. При переносе проекта для запуска и экспорта достаточно файла `.forge-project.json`. Для следующего переимпорта выберите исходник повторно. Если в манифесте отсутствуют записи библиотеки, при открытии или `validate` выводятся тип ресурса, ID или локальный индекс и затронутая сцена или префаб.

Те же операции доступны в CLI. ID модели и скрипта относятся к разным спискам. В командах ниже подставьте значения из `project-assets` и ID своей сцены:

```sh
forge3d-batch project-import game.forge-project.json door.fbx spin.rhai
forge3d-batch project-assets game.forge-project.json
forge3d-batch project-deps game.forge-project.json scene main
forge3d-batch project-uses game.forge-project.json script 1
forge3d-batch project-reimport game.forge-project.json model 1 updated.fbx
forge3d-batch project-reimport game.forge-project.json script 1 updated.rhai
forge3d-batch validate game.forge-project.json
```

Команды изменения проекта в CLI записывают результат атомарно и используют служебный файл `.forge3d-write.lock` для одновременных вызовов. Команды `project-models` и `project-reimport PROJECT MODEL_ID FILE` версии 1.0.5 по-прежнему доступны.

## Импорт текстовой карты GRID

[Пример island.grid](https://github.com/hjddfk9fzr-sketch/Forge3D/blob/v1.4.3/tests/fixtures/island.grid) задаёт контур острова. В UTF-8 файле каждая строка имеет одинаковую длину. Символ `#` создаёт ячейку платформы размером 1 × 1, а `.` оставляет пустоту. Поддерживаются до 64 строк и столбцов. Модель лежит в плоскости XZ, её верх находится на высоте Y = 0. Коллайдеры настраиваются отдельно.

1. Добавьте файл через **Assets → Batch import…**, затем разместите модель через **Project → Shared assets** в двух сценах.
2. Измените карту в текстовом редакторе. В **Where used… → Reimport model…** укажите изменённый файл. Геометрия обновится у обоих экземпляров, их положения сохранятся. Сохраните проект.
3. При опечатке редактор покажет строку и столбец. Проект продолжит использовать предыдущую геометрию.

Те же операции доступны из корня репозитория:

```sh
cargo run --locked --bin forge3d-batch -- project-import world.forge-project.json island.grid
cargo run --locked --bin forge3d-batch -- project-reimport world.forge-project.json model ID island.grid
```

Подставьте ID из вывода первой команды. Экспорт содержит готовый меш, поэтому игре достаточно экспортированных файлов.

### Свой импортёр на Rust

Добавьте декодер в `MODEL_IMPORTERS` в [src/import.rs](https://github.com/hjddfk9fzr-sketch/Forge3D/blob/v1.4.3/src/import.rs) и пересоберите редактор и CLI. Запись связывает расширения с функцией `ModelDecoder`, которая возвращает части модели и при необходимости анимационный риг. Если декодер читает связанные файлы, разрешайте их пути через `read_path` с переданным корнем проекта. Тот же реестр обслуживает первоначальный импорт и переимпорт.

## Освещение, материалы и анимация

### Детализация моделей по расстоянию

В проекте откройте **Assets → Where used…**, выберите статическую модель и нажмите **Add or replace LOD…**. Укажите файл более простой модели с тем же началом координат и масштабом, затем расстояние до точки привязки в единицах сцены. Повторный ввод того же расстояния заменяет уровень. Поддерживается до четырёх дополнительных уровней. Каждый следующий уровень должен содержать меньше треугольников. **Clear LOD levels…** удаляет уровни из выбранного ресурса. Сохраните проект после изменений.

Например, модель **Basalt column** в Cloud Relay использует 240, 72 и 24 треугольника. Пороги — 14 и 24 единицы. Чтобы модель не мерцала около границы, при удалении камера проходит 110% порога, а при приближении возвращается ниже 90%. 3D-окно и теневой проход используют один уровень на кадр. Коллайдеры и размещение объектов сохраняются. Запасные меши встраиваются в проект и экспорт и остаются прикреплёнными к модели при переимпорте основной геометрии.

```sh
cargo run --locked --bin forge3d-batch -- project-model-lod world.forge-project.json MODEL_ID 24 simpler.glb
cargo run --locked --bin forge3d-batch -- project-model-lod-clear world.forge-project.json MODEL_ID
```

### Освещение небом и профили теней

Снимите выделение объекта и откройте **Inspector → Lighting**. **Skybox** выбирает палитру Day, Sunset или Night, а **Sky lighting strength** задаёт силу её рассеянного света и отражений. Металл отражает палитру неба сильнее, а высокая шероховатость сглаживает отражение. При `0` или **Off** используется прежнее освещение. Отражения рассчитываются по палитре неба и его градиенту.

Для теней от солнца выберите **Shadow profile**. **Desktop** по умолчанию использует карту 1024 × 1024 и пять выборок фильтра, **Mobile** — 512 × 512 и одну выборку. **Shadow map** и **Shadow coverage** сохраняются отдельно для каждого профиля. Сцена и экспорт используют выбранный профиль независимо от устройства.

В Cloud Relay в начале `amber` и `vesper` стоят матовый и металлический образцы. Смените **Skybox**, чтобы сравнить обе поверхности в одной сцене. У `amber` выбран Desktop, у `vesper` — Mobile. Профили и освещение видны в игровом 3D-окне. Программный PNG-превью использует упрощённый свет.

### Карты нормалей

Forge3D импортирует `normalTexture` и её коэффициент `scale` из glTF/GLB. Если модель содержит тангенты, редактор использует их. Иначе он вычисляет их по UV и разделяет вершины на границах участков с противоположной ориентацией. При скелетной анимации тангенты деформируются вместе с вершинами.

Чтобы изменить интенсивность для экземпляра, откройте **Inspector → Material and light → Override normal strength**. Значение `0` выключает эффект. Снятие флажка восстанавливает силу из импортированного материала. В Cloud Relay выберите **Landing deck** в `amber` или `vesper` и сравните результат при `0` и `1`.

В beta.3 рендерер использует один UV-набор на примитив. Используйте для карты нормалей тот же набор, что и для остальных текстур материала. При разных наборах импорт сохраняет примитив и его остальные материалы, а карта нормалей для него пропускается. Рельеф виден в 3D-окне и экспортированной игре. Программный PNG-превью использует геометрические нормали.

### Пользовательский шейдер цвета

В **Scene settings → Edit scene color shader…** введите тело функции GLSL ES 1.00 или нажмите **Pulse example**, затем **Apply**. У нужного объекта включите **Inspector → Material and light → Override material → Use scene color shader**. Шейдер получает итоговый цвет материала `rgb`, координаты текстуры `uv` и время в секундах `time`. Например, эта строка создаёт пульсацию:

```glsl
return rgb * (0.65 + 0.35 * sin(time * 3.0 + uv.y * 6.28));
```

У каждой сцены своё тело функции (до 16 КиБ). Редактор проверяет его на GPU при применении и показывает ошибку компиляции. Пустое поле возвращает штатный цвет. Код сохраняется в проекте и попадает в экспортированную игру. При ошибке драйвера во время загрузки игра использует обычный материал и пишет причину в журнал. Программный предпросмотр PNG использует упрощённое освещение.

В **Scene settings → Lighting** задайте цвет и направление солнца, интенсивность, фоновое освещение и размер области теней. Для локального света добавьте **Point light** в инспекторе объекта. Рендер учитывает четыре ближайших к камере точечных источника. Тени от солнца строятся по карте глубины 1024×1024. Объекты могут отключить отбрасывание тени через **Cast shadows**.

PBR-рендер использует модель metallic–roughness с прямым светом. Импорт glTF и GLB сохраняет базовый цвет, metallic, roughness, emissive, цветовую текстуру и карты metallic–roughness и emissive, использующие ту же UV-развёртку. **Material and light** позволяет переопределить значения на конкретном объекте. Карты нормалей, освещение от окружения и морф-цели остаются вне этого релиза.

Для анимации поддерживаются преобразования узлов, скелетное смешивание до четырёх весов на вершину и ключи STEP, LINEAR и CUBICSPLINE. При добавлении модели редактор выбирает её первый клип. В **Animation** можно переключить клип, задать стартовое время, паузу, повтор и скорость, в том числе обратное воспроизведение. PNG через MCP показывает заданную позу с упрощённым программным освещением.

## Cloud Relay, skybox и наследование префабов

**Project → Open Cloud Relay… → Play** открывает игру про курьера на парящих островах. Нажмите Enter, двигайтесь клавишами WASD или стрелками и прыгайте пробелом. На каждом из двух уровней пройдите через обе светящиеся арки по порядку. Падение перезапускает текущий уровень. На сенсорном экране доступны стрелки и Jump.

Выберите корневой объект арки и откройте **Inspector → Gameplay components → RelayGate**. Роль **Transmitter** заряжает курьера, роль **Exit** отправляет заряженного курьера в сцену из списка **Destination**. Арки можно переименовывать. У связанных экземпляров изменения роли и назначения видны в списке переопределений префаба.

Чтобы получить редактируемый проект и самостоятельные исходники игры:

```sh
cargo run --locked --bin forge3d-batch -- cloud-relay Cloud-Relay.forge-project.json
cargo run --locked --bin forge3d-batch -- export Cloud-Relay.forge-project.json cloud-relay-game
```

Снимите выделение объекта и выберите **Inspector → Lighting → Skybox**. Доступны Day, Sunset, Night и Off. Небо привязано к направлению камеры и сохраняется в сцене.

Новые экземпляры префаба запоминают источник и ID исходного узла. Измените свойство связанного объекта и выберите **Apply to prefab** в Inspector. Изменение получат все экземпляры, которые наследуют это свойство. **Revert** возвращает одному свойству текущее значение префаба. Например, можно обновить толщину стойки арки на обоих уровнях Cloud Relay, сохранив индивидуальный цвет подсветки. Положение и поворот корня остаются локальными. Существующие копии из 1.3.1 продолжают работать как самостоятельные объекты.
